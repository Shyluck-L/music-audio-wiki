# 取樣率（Sampling Rate）

> **一句話白話結論**：取樣率代表電腦每秒對聲音「拍照」測量的次數，它唯一決定的就是音訊能記錄的「最高聲音頻率」。

## 概念說明
自然界的聲音是連續變化的類比聲波。當麥克風將聲音轉為電壓訊號後，類比數位轉換器（ADC）會以固定的時間間隔量測電壓數值，這個每秒記錄的次數就稱為「取樣率（Sampling Rate）」，單位為赫茲（Hz）或千赫茲（kHz）。

取樣率並不是越高就代表波形越平滑，根據奈奎斯特–夏農取樣定理（Nyquist-Shannon Sampling Theorem），取樣率決定了數位訊號能忠實還原的最高頻率上限（稱為奈奎斯特頻率，Nyquist Frequency），其數值剛好等於取樣率的一半。

## 重點整理
* **最高聲音頻率由取樣率決定（奈奎斯特定理）**：若要記錄最高頻率為 $f$ 的聲音，每秒測量的次數必須達到 $2f$ 以上（也就是最高頻率等於取樣率的一半）。人耳極限聽覺頻率約為 20 kHz（20,000 Hz），因此取樣率至少需 40 kHz 才能涵蓋人耳可聽範圍。
* **混疊失真（Aliasing）**：如果輸入的聲音頻率超出上限，多出來的超高頻訊號無法正常記錄，反而會「折射」回可聽範圍內變成刺耳的數位雜音。
* **抗混疊濾波器（Anti-Aliasing Filter）**：在將聲音轉換為數位訊號前，硬體必須先用低通濾波器把過高的頻率切掉。但現實中的濾波器無法像懸崖一樣垂直一刀切斷（即所謂的「磚牆濾波」），而是需要一小段「緩衝過渡頻帶（Transition Band）」逐漸減弱。
* **常見取樣率規格的日常應用**：
  * **8 kHz (8,000 Hz)**：傳統電話通話標準（G.711），僅保留 3.4 kHz 以下語音頻率，足夠聽懂說話內容但音質單薄。
  * **44.1 kHz**：CD 音質標準。頻率上限為 22.05 kHz，在人耳極限 20 kHz 外留有約 2.05 kHz 的濾波緩衝空間。
  * **48 kHz**：影視影音、電腦系統與多數藍牙設備預設標準，預留了 4 kHz 濾波緩衝，是現代數位影音最通用的規格。
  * **96 kHz / 192 kHz**：高解析音訊（Hi-Res Audio），主要用於專業錄音室母帶後製、極端降速音效處理或特殊科學記錄。

## 生活類比
> [!NOTE] [補充說明] 生活類比
> 許多人常把取樣率比喻為影片的「每秒影格數（FPS）」，以為影格越多動作越平滑。但在音訊物理上這個比喻並不精確：數位音訊在播放轉換為類比訊號時，會透過重建濾波器平滑還原出平滑波形，而非階梯狀。更貼切的直覺是「光譜捕蟲網」：取樣率多高，網子就能攔截多高頻率的聲波，網子以外的高頻若不先過濾掉，反而會掉進網內變成干擾雜音。

## 實務應用與選擇建議
* **一般音樂聆聽與串流**：44.1 kHz 或 48 kHz 已完整涵蓋人耳極限（20 Hz～20 kHz），能滿足絕大多數日常播放環境的需求。
* **音樂製作與錄音**：推薦使用 48 kHz 或 96 kHz 進行專案錄音與混音，這能為非線性處理（如飽和度、壓縮效果）提供充足的安全餘裕。
* **超高取樣率（176.4 kHz / 192 kHz）**：除非涉及大幅度的降調音效設計（Pitch shifting）或特殊科學錄音，否則會佔用雙倍以上的儲存空間與運算資源，且過短的測量時間反而可能引入電壓測量誤差。

## 常見迷思與 FAQ
* **Q：取樣率越高，波形看起來比較不鋸齒，聲音就一定越細緻嗎？**
  * A：這是常見誤解。數位音訊中不存在「階梯形鋸齒」，播放端的數位類比轉換器（DAC）會利用濾波器將取樣點精確重建為平滑的連續波形。取樣率提高的本質是拓展能記錄的最高頻率，而非讓既有頻率更平滑。
